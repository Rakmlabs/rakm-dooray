0.1.8 에서 올라오면 이 버전은 **자동으로 설치됩니다** (받아 둔 뒤 "지금 재시작", 또는 다음에 앱을 끌 때).

## 새 버전이 나오면 바로 알려 드립니다
- 새 버전 확인을 4시간마다 → 15분마다, 그리고 앱을 켤 때·창으로 돌아올 때·잠자기에서 깰 때 합니다.
- 다 받으면 macOS 알림과 함께 오른쪽 위에 알림 카드가 뜹니다. 카드에는 이번 버전의 변경점이 보이고 [지금 재시작] [나중에] 를 고를 수 있습니다.
- "나중에"를 누르면 다음에 앱을 끌 때 설치됩니다. 설정 아이콘에 작은 점이 남아 있습니다.
- 글을 입력하는 중에는 카드가 뜨지 않고, 손을 뗀 뒤에 뜹니다. 화면을 밀지 않고 위에 떠 있습니다.

## 더 가볍고 빠르게
- 앱을 켤 때 읽는 코드가 2.5MB → 0.5MB 로 줄었습니다 (압축, 위키 편집기는 위키를 열 때 불러옴). 켤 때 스크립트 컴파일 시간이 절반 아래로 줄었습니다.
- 보관함 검색을 따로 돌려, 메시지가 아주 많을 때(30만 개) 검색하는 동안 앱이 0.1초 가까이 멈칫하던 것이 없어졌습니다.
- 메시지가 많을 때 앱을 켤 때마다 보관함 전체를 한 번 훑던 일을 없앴습니다 (30만 개 기준 약 0.1초).
- 위키 본문 사진은 화면 가까이 올 때 받고, 메모리에 들고 있는 양에 상한(64MB)을 두었습니다.
- 자리를 비웠을 때(화면 잠금, 10분 넘게 입력 없음)는 뒤에서 대화방을 훑는 횟수를 줄입니다. 새 메시지 알림은 그대로 옵니다 (최대 1분 늦을 수 있음).
