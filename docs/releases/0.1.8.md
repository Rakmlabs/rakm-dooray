## 입력이 바로 반응합니다
- 메시지가 많이 쌓인 방에서 글자를 칠 때 생기던 끊김을 없앴습니다 (3,100개 불러온 방 기준 키 입력 지연 p95 832ms → 15ms).
- 가만히 있어도 3초마다 화면이 멈칫하던 문제(폴링 때 목록 전체 다시 그리기)를 고쳤습니다.
- 입력창 높이는 글자에 맞춰 늘어나되 목록이 흔들리지 않습니다.

## 사진 여러 장 묶어 보내기 (최대 30장)
- 끌어 놓기·붙여넣기·첨부 버튼으로 고른 파일이 입력창 위 트레이에 모입니다. 보내기 전에 순서를 바꾸거나(끌기, ⌘/⌥ + ←→) 뺄 수 있습니다.
- 올리는 동안 진행률을 보여 주고, 실패한 것만 다시 보낼 수 있습니다. 일시적인 실패는 한 번 자동으로 다시 시도합니다.
- 순서가 꼬이지 않도록 하나씩 차례로 올립니다.
- 같은 사람이 연달아 보낸 사진은 카톡처럼 격자(앨범)로 묶어 보이고, 누르면 뷰어에서 좌우로 넘길 수 있습니다.

## 보내는 중 · 실패 · 다시 보내기
- 엔터를 누르면 메시지가 바로 목록에 "보내는 중…"으로 나타납니다. 실패하면 그 자리에 "다시 보내기 / 지우기"가 뜹니다.
- 인터넷이 끊겼을 때 영어 오류("fetch failed") 대신 한국어 안내가 나옵니다.

## 메시지가 아주 많아도 가볍게
- 보이는 부분만 그립니다. 3,100개를 불러와도 화면에는 최대 360개만 있어 메모리 59.8MB → 28.4MB, 맨 아래로 돌아오면 9.8MB.
- 위로 올리면 자리를 지키며 이어서 불러옵니다 (3,100개까지 14.7초 → 2.5초).
- 로컬 보관함에 인덱스를 추가해 안 읽은 수 계산이 빨라졌습니다.

## 알아 두실 점
- 두레이 API 는 메시지 하나에 파일 하나만 붙일 수 있어, 30장은 사진 메시지 30개로 올라갑니다. 이 앱에서는 앨범으로 묶여 보이고, 두레이 웹·모바일에서는 연달아 올라온 사진으로 보입니다.
